JAK SE PŘIPOJIT

Čtyři kroky a můžeš hrát.

1

Spusť Minecraft

Java Edition 1.21.11 → Multiplayer → Přidat server.

2

Vlož IP adresu

Zkopíruj IP tlačítkem Hrát nahoře a vlož ji do „Adresa serveru".

3

Potvrď „Ano"

Server nabídne svůj vzhled. Klikni Ano a uvidíš 3D modely a vlastní menu.

4

Hraj!

Kompas v lobby otevře minihry. Nezapomeň na /odmena.
